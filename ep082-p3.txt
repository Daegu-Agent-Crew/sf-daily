#082 「주홍색 역병」(The Scarlet Plague, 잭 런던, 1912) — 3페이지 칸만화 생성 지시 (3페이지) · 말풍선 B안

너(당신)는 내장 image_gen 도구로 한국어 말풍선·내레이션 박스가 그림에 직접 포함된 만화 페이지 1장을 생성한다. 모든 지시를 그대로 따르고, 스크립트는 수정 없이 실행한다. git 명령 사용 금지.

## 고정 스타일 블록 (모든 이미지 프롬프트 첫머리에 그대로 삽입)
bright casual webtoon style, vivid pastel colors (sky blue, cream, coral, mint), soft bold linework, rounded friendly character design, expressive exaggerated faces, flat colors, cheerful bright lighting, clean readable composition

## 공통 사양
- 페이지: 1024x1536 세로, 2x3 여섯 칸 그리드(왼쪽→오른쪽, 위→아래 읽기), 흰 여백 거터, 칸 테두리 둥근 사각
- 시대·배경: 2073년 여름의 캘리포니아 해안 — 이야기의 프레임으로 돌아온다. 3페이지는 예순 해 뒤의 해변: 책을 숨긴 동굴, 무당을 꿈꾸는 소년들, 조용히 세계를 꿈꾸는 에드윈, 그리고 저녁 해변에 내려온 야생마 떼. 종말이 끝이 아니라 주인이 바뀐 것임을 보여주는 여운의 페이지
- 캐릭터·배경 시트(1~3페이지 동일 유지 — 이 문장을 그대로 재사용해 연속성을 지킨다):
  그랜서(2073년 노인): 아주 늙은 노인 — 떨리는 몸, 굵은 나무 지팡이, 염소가죽 스컬캡 모자, 허리까지 닿는 엉클고 때 묻은 새하얀 수염, 큰 잎으로 만든 눈가림 바이저, 한 장의 염소가죽 옷, 야윈 팔다리
  젊은 스미스(2013년 회상 속 주인공): 스물일곱의 영문학 강사 — 다듬은 짧은 갈색 머리, 둥근 안경, 트위드 재킷과 조끼에 넥타이, 온화한 젊은 학자 얼굴
  에드윈(12세 소년): 구운 듯한 갈색 피부, 짙고 파란 날카로운 눈, 머리를 끼운 곰 가죽 한 장 옷, 귀에 꽂은 돼지 꼬리, 등에 활과 화살통
  헤어립(소년): 언청프 입술의 사나운 눈썹 소년, 개 가죽옷, 몽둥이를 짚은 거친 인상
  후후(소년): 더 어리고 장난기 가득, 뾰족하게 웃는 얼굴, 짧은 갈색 머리, 가죽 조끼
  배경: ①2073년 해변 — 넓은 모래사장(옛 샌프란시스코 해안), 모래에 반쯤 묻힌 무너진 벽돌과 콘크리트 잔해, 검은 바위 위 물개들, 백사장 끝의 무성한 숲, 나무가 삼킨 옛 철길 둑 ②산 중턱의 마른 동굴(어두운 구멍, 안쪽에 두꺼운 책 무더기와 놋쇠 열쇠가 옅게 보임 — 책 등은 무지개색 사각형으로만, 글자 없음) ③저녁 해변 — 부채꼴로 쏟아지는 붉은 빛줄기, 물보라, 야생마 떼(붉은 갈기의 숫말이 물보라 속에 서 있고 암말과 망아지들이 뒤따름)
  소도구: 지팡이, 가죽 물주머니, 염소 떼와 개, 활과 화살, 몽둥이, 옷에 꽂은 돼지 꼬리, 두꺼운 책 무더기와 놋쇠 열쇠, 갈고리 목의 붉은 갈기 숫말, 바위 위 물개들

## 말풍선 B안 — 텍스트 렌더 규칙 (절대 준수)
- 대사 풍선: 흰 바탕의 둥근 풍선, 그림 선과 같은 굵기의 검은 외곽선, 꼬리는 화자의 입 쪽을 향한다. 풍선은 칸의 빈 공간(하늘·단색 배경·바닥·벽)에만 놓고, 인물의 얼굴·액션·핵심 소도구를 절대 가리지 않는다. 풍선 하나는 최대 2줄, 면적은 칸의 1/4 이하
- 속삭임 풍선: 점선 외곽선의 흰 풍선. 절규 풍선: 가장자리가 톱니 모양인 흰 풍선
- 내레이션: 풍선이 아니라 칸 상단 또는 하단 테두리에 붙은 가로로 긴 사각 박스 — 크림색 반투명 바탕, 얇은 검은 테두리
- 한글 렌더: 아래 지정 문구를 한 글자도 틀리지 말고 선명하게 그대로 쓴다. 깨진 글자·알 수 없는 기호·지정되지 않은 글자·영어·숫자·로고 절대 금지(단, 지정 문구에 포함된 표기는 그대로). 문구를 구획하는 「」 기호는 프롬프트 표기일 뿐 그림에 넣지 않는다. 지정에 없는 마침표·느낌표·문장부호를 임의로 추가하는 것도 금지. 둥근 한글 고딕체, 가독 크기, 부드러운 안티앨리어싱
- 무음 칸(텍스트 지정 없음)에는 텍스트를 일절 넣지 않는다
- 책·금화·동굴 벽 등 소도구에는 지정 문구 외 읽을 수 있는 글자를 넣지 않는다(가늘고 알아볼 수 없는 선 정도만)

## 직전 페이지 참조 체인
직전 페이지(.work/ep082-p2.png)의 마지막 칸은 새벽 안개의 들판에서 죽은 두 동행과 조랑말 곁에 홀로 선 젊은 스미스였다 — 이 페이지는 예순 해 뒤(2073년)의 해변으로 돌아온다. 그랜서(염소가죽의 백발 노인)와 세 소년(에드윈·헤어립·후후)의 외형을 1페이지와 동일하게 유지한다

## 3페이지 저장 경로: .work/ep082-p3.png
칸1(미들): 해변 뒤 언덕 — 그랜서가 지팡이로 산 중턱의 마른 동굴(어두운 구멍)을 가리키고, 곁의 에드윈이 올려다본다. 동굴 안에 두꺼운 책 무더기와 놋쇠 열쇠가 옅게 보인다. 앵글은 두 사람과 동굴을 담는 사이드 미들

  → 그랜서의 말풍선 2: 「알파벳의 열쇠와 함께 — 다시 읽는 날을 위해」 — 풍선은 동굴 쪽 빈 공간, 꼬리는 그랜서의 입
칸2(작게): 해변 모래 위 — 후후가 이를 드러내고 자랑하듯 웃고, 헤어립이 팔짱을 끼고 코웃음 친다. 앵글은 두 소년의 투샷 클로즈업
  → 후후의 말풍선: 「난 어른이 되면 — 무당이 될 거야」 — 풍선은 하늘 빈 공간, 꼬리는 후후의 입
  → 헤어립의 말풍선: 「주문이 안 통하면 — 머리를 부숴 주지」 — 풍선은 반대쪽 빈 공간, 꼬리는 헤어립의 입
칸3(작게): 에드윈의 클로즈업 — 짙은 파란 눈이 그랜서 쪽을 향하고 입가에 소곤거리는 미소. 배경이 옅게 번진 원경의 그랜서(심리화). 앵글은 얼굴 클로즈업
  → 에드윈의 속삭임 풍선(점선 외곽선): 「할아버지는 바보가 아니야」 — 풍선은 위 빈 공간, 꼬리는 에드윈의 입
  → 에드윈의 속삭임 풍선 2(점선 외곽선): 「언젠가 내가 — 이 무리 전부를 다스린다」 — 풍선은 아래 빈 공간, 꼬리는 에드윈의 입

## 연출 설계
- 단일 효과: 남은 것 — 종말이 끝이 아니라 주인이 바뀐 것임을 깨닫는 긴 여운. 모든 칸은 이 정서에 복종한다
- 칸 크기 리듬: 칸1 미들 → 칸2 작게 → 칸3 작게 → 칸4 미들 → 칸5 크게 → 칸6 크게(무음 스플래시 여운)
- 전환 설계: 칸1→2 순간→순간(노인의 이야기→소년들의 반응), 칸2→3 개념→개념(무당을 꿈꾸는 소년들→조용히 세계를 꿈꾸는 에드윈 — 대비의 비약), 칸3→4 장면→장면(속삭임→떠나는 대열), 칸4→5 개념→개념(지나간다는 말→살아 돌아온 야생 — 지나가고 남은 것), 칸5→6 행위→행의(말을 확인하다→숲으로 걷다)
- 인지 반전: 같은 해변이 다르게 보인다 — 1페이지 첫 칸의 해골이 파묻힌 죽음의 해변이, 마지막 칸에서 야생마와 물개가 사는 바다가 된다
- 환형: 1페이지 첫 칸(죽음이 파묻힌 해변) ↔ 칸6(살아 돌아온 해변), 금화(죽은 문명의 유물) ↔ 동굴의 책과 열쇠(살아남은 문명의 씨앗)
- 앵글 혼합: 사이드 미들 → 투샷 클로즈업 → 얼굴 클로즈업 → 와이드 → 로우 와이드 → 대원경 와이드(인접 칸 같은 앵글 없음)
- 마지막 칸: 텍스트 없는 환형 구도로 여운을 닫는다

## 절차
1. 3페이지 이미지 프롬프트 = 고정 스타일 블록 + 사양 + 시트 + 말풍선 렌더 규칙 + 직전 페이지 참조 + 칸1~6(장면+텍스트)을 모두 반영해 image_gen으로 생성 → .work/ep082-p3.png 저장
2. python3 PIL로 검증: PNG, 1024x1536, 300,000바이트 이상. 실패 시에만 재생성(성공하면 절대 재생성 금지)
