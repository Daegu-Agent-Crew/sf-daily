#059 「도웰 교수의 머리」 — 3페이지 칸만화 생성 지시 (2페이지, 1페이지 참조 첨부)

첨부한 이미지는 이번 화의 완성된 1페이지(.work/ep059-p1-notext.png)다 — 같은 캐릭터 시트, 같은 팔레트, 같은 붓결을 그대로 이어 받아 2페이지를 그린다. 너(당신)는 내장 image_gen 도구로 no-text 만화 페이지 1장을 생성한다. 모든 지시를 그대로 따르고, 스크립트는 수정 없이 실행한다. git 명령 사용 금지.

## 고정 스타일 블록 (모든 이미지 프롬프트 첫머리에 그대로 삽입)
bright casual webtoon style, vivid pastel colors (sky blue, cream, coral, mint), soft bold linework, rounded friendly character design, expressive exaggerated faces, flat colors, cheerful bright lighting, clean readable composition

## 공통 사양
- 페이지: 1024x1536 세로, 2x3 여섯 칸 그리드(왼쪽→오른쪽, 위→아래 읽기), 흰 여백 거터, 칸 테두리 둥근 사각
- 절대 규칙: 어떤 글자·숫자·로고·말풍선·캡션 박스도 그림에 넣지 않는다(NO TEXT). 텍스트는 나중에 오버레이한다
- 캐릭터·배경 시트(1페이지와 동일 유지):
  마리 로랑: 20대 후반의 젊은 여성 의사, 짧게 웨이브 진 밤색 단발 머리, 둥근 눈과 총명한 표정, 크림색 블라우스에 민트색 스카프, 긴 갈색 스커트
  케른 교수: 50대의 작고 다부진 체격, 매만진 회색 머리와 짧은 회색 콧수염, 차가운 옅은 눈, 진회색 양복에 조끼
  도웰 교수의 머리: 60대 지적인 마른 얼굴, 희끗한 짧은 머리와 옅은 흰 수염, 온화하고 깊은 눈 — 하늘색 영양액이 찬 둥근 유리 돔 안에 떠 있고 목 끝에 가는 유리관과 거품

## 2페이지 저장 경로: .work/ep059-p2-notext.png
(칸1~3은 부드럽게 세피아빛이 감도는 따뜻한 회상 톤, 칸4~6은 현재 시점)
칸1(회상, 미디엄): 병든 도웰 교수의 병상 — 창밽하게 웃으며 젊은 시절의 케른(회색 머리가 덜 샌 젊은 버전)에게 무언가를 당부하듯 손을 내미는 노교수, 침대 곁 책상 위의 의학서와 작은 화분
칸2(회상, 클로즈업): 유리 돔 속에서 눈을 뜨는 도웰의 머리 — 첫 광경은 둥근 유리 너머의 천장 등과 그곳을 내려다보는 케른의 얼굴, 하늘색 영양액 속으로 올라가는 작은 거품들
칸3(회상, 부감 와이드): 실험실 전체 — 배양조 여러 개가 늘어서 있고 그중 옆 조에는 흰빛 도는 회색털 늙은 개의 머리가 온순한 눈으로 살아 있음, 각 조에서 은은한 민트·하늘빛
칸4(현재, 로우앵글 긴장): 유리 돔을 손가락으로 톡톡 두드리며 차갑게 내려다보는 케른의 클로즈업 — 돔 속 도웰의 머리는 눈을 감은 채 평온, 배경에 구리 배관의 그림자
칸5(현재, 따뜻한 미디엄): 밤의 실험실 — 마리가 돔 곁에 나무의자를 붙이고 앉아 무릎 위 노트를 받치고 웃으며 이야기 나누고, 돔 속 머리도 오랜만에 눈웃음 — 등불의 따뜻한 주황빛
칸6(클로즈업 훅): 진지해진 도웰의 머리가 유리에 가까이 다가와 마리를 향해 나직히 속삭이고, 마리의 시선이 서랍장의 세 번째 칸을 향함 — 서랍 틈으로 은은하게 빛나는 낡은 노트의 가장자리

## 절차
1. 2페이지 프롬프트 = 고정 스타일 블록 + 사양 + 시트 + 칸1~6 묘사 + 첨부 1페이지 참조. image_gen으로 생성 → .work/ep059-p2-notext.png 저장
2. python3 PIL로 검증: PNG, 1024x1536, 300,000바이트 이상. 실패 시에만 재생성(성공하면 절대 재생성 금지)
