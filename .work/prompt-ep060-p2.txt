#060 「다른 세계 여행」 — 3페이지 칸만화 생성 지시 (2페이지, 1페이지 참조 첨부)

첨부한 이미지는 이번 화의 완성된 1페이지(.work/ep060-p1-notext.png)다 — 같은 캐릭터 시트, 같은 팔레트, 같은 붓결을 그대로 이어 받아 2페이지를 그린다. 너(당신)는 내장 image_gen 도구로 no-text 만화 페이지 1장을 생성한다. 모든 지시를 그대로 따르고, 스크립트는 수정 없이 실행한다. git 명령 사용 금지.

## 고정 스타일 블록 (모든 이미지 프롬프트 첫머리에 그대로 삽입)
bright casual webtoon style, vivid pastel colors (sky blue, cream, coral, mint), soft bold linework, rounded friendly character design, expressive exaggerated faces, flat colors, cheerful bright lighting, clean readable composition

## 공통 사양
- 페이지: 1024x1536 세로, 2x3 여섯 칸 그리드(왼쪽→오른쪽, 위→아래 읽기), 흰 여백 거터, 칸 테두리 둥근 사각
- 절대 규칙: 어떤 글자·숫자·로고·말풍선·캡션 박스도 그림에 넣지 않는다(NO TEXT). 텍스트는 나중에 오버레이한다
- 캐릭터·배경 시트(1·2·3페이지 동일 유지 — 이 문장을 그대로 재사용해 연속성을 지킨다):
  베어워든: 40대 건장한 미국인 발명가·기업가, 짙은 밤색 짧은 머리와 통통하고 다부진 수염, 너트브라운 탐험 재킷에 금동 단추, 자신만만한 환한 웃음, 목에 황동 망원경
  코틀랜드트: 50대 마른 정부 과학자, 희끗한 곱슬 머리와 둥근 안경, 청회색 빅토리안 연미복과 조끼, 늘 두꺼운 수첩, 신중하면서도 코믹한 표정
  에이롤트: 30대 날렵한 천문학자, 밀짚색 부드러운 머리와 다정한 눈, 크림색 셔츠에 코랄색 넥타이, 어깨에 은빛 고전 카메라
  카리스토호: 크림화이트 둥근 타원 동체에 구리색 리벳과 둥근 창문 셋, 지붕 위 황도재 안테나, 바닥 둘레에 하늘색 발광 반발력 링이 빛는 귀여운 빅토리아풍 우주선
  배경(1페이지): 서기 2000년의 뉴욕 — 공중 도로를 나는 소형 비행정, 온실로 물든 온화한 기후

## 2페이지 저장 경로: .work/ep060-p2-notext.png
칸1(와이드, 크게): 목성 표면의 초대형 정글 — 저택보다 큰 이끼 장미와 산호빛 거대 버섯 숲, 착륙한 카리스토호 곁에 개미처럼 작아 보이는 세 탐험가
칸2(미디엄): 거수와의 조우 — 코끼리 두 배 크기의 온순한 초록 피부 초식 거수가 호기심 가득한 큰 눈으로 고개를 숙여 내려다보고, 세 사람은 씩 웃으며 손을 흔듦
칸3(클로즈업): 베어워든이 전기총으로 노란 번개빛 그물을 쏘는 순간 — 등 뒤에서 덮치던 날카로운 이빨의 육식 거수가 번개 그물에 휩싸여 새파랗게 질린 표정
칸4(무음 칸, 느린 리듬): 협곡 끝의 장엄한 광경 — 형광 민트빛 폭포 앞에서 말을 잃은 세 사람의 실루엣, 하늘에는 목성의 두 개의 해가 나란히
칸5(앙각): 카리스토호 바닥의 반발력 링이 활짝 펼쳐져 하늘색 역장 돔으로 거대 포식자를 밀어내는 모습 — 돔에 부딪힌 거수가 물구나무 자세로 튕겨 나가는 코믹한 순간
칸6(미디엄 훅): 귀환한 조종실 — 창밖으로 토성의 은빛 고리가 아치로 걸리고, 에이롤트가 황동 상자(강령 통신기 프로토타입)를 무릎에 올리고, 코틀랜드트는 불안한 웃음, 베어워든은 팔짱을 낀 진지한 얼굴

## 절차
1. 2페이지 프롬프트 = 고정 스타일 블록 + 사양 + 시트 + 칸1~6 묘사 + 첨부 1페이지 참조. image_gen으로 생성 → .work/ep060-p2-notext.png 저장
2. python3 PIL로 검증: PNG, 1024x1536, 300,000바이트 이상. 실패 시에만 재생성(성공하면 절대 재생성 금지)
