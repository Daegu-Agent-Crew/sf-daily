#064 「메트로폴리스」(Metropolis, 1925) — 3페이지 칸만화 생성 지시 (1페이지)

너(당신)는 내장 image_gen 도구로 no-text 만화 페이지 1장을 생성한다. 모든 지시를 그대로 따르고, 스크립트는 수정 없이 실행한다. git 명령 사용 금지.

## 고정 스타일 블록 (모든 이미지 프롬프트 첫머리에 그대로 삽입)
bright casual webtoon style, vivid pastel colors (sky blue, cream, coral, mint), soft bold linework, rounded friendly character design, expressive exaggerated faces, flat colors, cheerful bright lighting, clean readable composition

## 공통 사양
- 페이지: 1024x1536 세로, 2x3 여섯 칸 그리드(왼쪽→오른쪽, 위→아래 읽기), 흰 여백 거터, 칸 테두리 둥근 사각
- 절대 규칙: 어떤 글자·숫자·로고·말풍선·캡션 박스도 그림에 넣지 않는다(NO TEXT). 텍스트는 나중에 오버레이한다
- 캐릭터·배경 시트(1~3페이지 동일 유지 — 이 문장을 그대로 재사용해 연속성을 지킨다):
  프레더: 20대 초반의 상냥한 금발 곱슬머리 청년, 크고 순한 눈과 다정한 둥근 얼굴, 흰색·하늘색 운동복 차림(위 도시의 아들), 칸4부터는 검은 노동자 작업복으로 갈아입은 모습
  마리아: 노동자 구역의 처녀, 곱게 땋아 넘긴 어두운 갈색 머리, 소박한 크림색 잿빛 원피스와 흰 머리두건, 맑고 자애로운 눈
  노동자 11811: 프레더와 키가 비슷한 소심한 눈의 젊은 노동자, 검은 작업복, 지친 회색 얼굴
  노동자들: 지하 기계홀의 검은 작업복 사람들, 다이얼 앞에 몸을 기울이는 반복된 자세
  아이들: 깡마른 뺨의 노동자 구역 아이들, 남루한 크림·민트·코랄빛 옷
  배경: 메트로폴리스 — 위쪽은 하늘빛·크림빛 고층 타워 숲과 탑 사이 공중 자동차 도로, 지상의 꽃과 분수가 흐르는 "영원한 정원", 땅속은 이글거리는 거대 기계홀(다이얼·압력계·파이프), 노동자 도시의 낮은 집들, 촛불의 카타콤 예배 동굴, 성당 광장과 종탑

## 1페이지 저장 경로: .work/ep064-p1-notext.png
칸1(와이드, 크게, 부감): 새벽의 메트로폴리스를 위에서 내려다본 전경 한 장 — 화면 윗부분은 하늘빛·크림빛 고층 타워 숲과 탑 사이 나르는 작은 공중 자동차들, 화면 아래쪽은 땅속 깊은 기계홀의 이글거리는 주황 불빛과 증기, 도시의 위와 아래가 한 화면 안에서 맞닿는 구도
칸2(미디엄 투샷, 수평): 지상의 "영원한 정원" — 꽃과 분수 사이 하얀 옷의 젊은들이 뛰노는 밝은 정원에 흰 운동복의 프레더가 멈춰 서서, 흰 두건의 마리아가 이끄는 깡마른 아이들 한 줄을 처음 바라보는 만남, 아이들의 크고 그늘진 눈과 프레더의 놀란 얼굴이 마주 보는 구도
칸3(클로즈업): 정원의 아이 하나가 프레더를 올려다보는 얼굴 클로즈업 — 여윈 뺨의 이지러진 큰 눈, 아이의 작게 뻗은 손끝, 화면 가장자리로 마리아의 다정한 시선이 살짝 겹침, 부드러운 꽃잎 빛
칸4(와이드, 측면): 지하 기계홀 — 검은 작업복으로 갈아입은 프레더가 커다란 시계 다이얼 모양 계기판 앞에서 두 팔을 쫙 벌려 바늘 자리를 잡은 채 서 있고, 좌우로 같은 자세의 지친 노동자들이 줄지어 늘어선 수평 구도, 새하얀 증기와 빽빽한 파이프
칸5(최대 칸, 다이내믹 앙각): 기계 폭발의 순간 — 증기와 불꽃이 하늘로 터져 오르고 노동자 몇이 허공으로 들려 올라가는 와중, 기계 홀 전체가 눈을 벌린 거대한 신전 입구처럼 일그러져 보이는 환영(프레더의 눈에 비친 몰로크), 이글거리는 좌우 대칭 구도
칸6(클로즈업, 정면): 프레더의 절규하는 얼굴 정면 클로즈업 — 크게 뜬 눈과 벌어진 입, 이글거리는 주황 빛이 얼굴에 닿고, 턱 아래로 뻗은 떨리는 두 손

## 절차
1. 1페이지 프롬프트 = 고정 스타일 블록 + 사양 + 시트 + 칸1~6 묘사. image_gen으로 생성 → .work/ep064-p1-notext.png 저장
2. python3 PIL로 검증: PNG, 1024x1536, 300,000바이트 이상. 실패 시에만 재생성(성공하면 절대 재생성 금지)
