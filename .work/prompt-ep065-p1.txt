#065 「해방된 세계」(The World Set Free, 1914) — 3페이지 칸만화 생성 지시 (1페이지)

너(당신)는 내장 image_gen 도구로 no-text 만화 페이지 1장을 생성한다. 모든 지시를 그대로 따르고, 스크립트는 수정 없이 실행한다. git 명령 사용 금지.

## 고정 스타일 블록 (모든 이미지 프롬프트 첫머리에 그대로 삽입)
bright casual webtoon style, vivid pastel colors (sky blue, cream, coral, mint), soft bold linework, rounded friendly character design, expressive exaggerated faces, flat colors, cheerful bright lighting, clean readable composition

## 공통 사양
- 페이지: 1024x1536 세로, 2x3 여섯 칸 그리드(왼쪽→오른쪽, 위→아래 읽기), 흰 여백 거터, 칸 테두리 둥근 사각
- 절대 규칙: 어떤 글자·숫자·로고·말풍선·캡션 박스도 그림에 넣지 않는다(NO TEXT). 텍스트는 나중에 오버레이한다
- 캐릭터·배경 시트(1~3페이지 동일 유지 — 이 문장을 그대로 재사용해 연속성을 지킨다):
  홀스텐: 30대 초반의 마른 젊은 화학자, 부스스한 밤색 머리와 둥근 안경, 하얀 와이셔츠 소매를 걷고 때묻은 흰 실험실 가운, 놀라면 눈이 동그래지는 순진한 얼굴
  러틀리지 노교수: 흰 구레나룻의 넉넉한 노과학자, 짙은 초록 조끼와 갈색 저지, 홀스텐의 은사
  군수 장교: 곧은 자세의 코랄빛 군복 장교, 흰 장갑
  조종사: 갈색 가죽 비행복과 헬멧, 하늘색 스카프의 젊은 얼굴
  피난민: 크림·코랄 담요를 두른 온화한 군중과 아이들
  에그버트 왕: 은발을 단정하게 넘긴 부드러운 얼굴의 왕, 금빛 왕관과 자수 놓은 망토
  카레닌: 75세의 야윈 현자, 하얀 머리와 짧은 흰 수염, 잿빛 심플한 옷, 반쯤 감긴 온화한 눈
  배경: 1930년대 다락 실험실(유리기구·계기판·종이 더미), 석탄 굴뚝이 사라진 밝은 원자력 도시(은빛 탑·공중 도로·민트빛 옥상 정원), 1956년 새벽의 폭격기 편대, 멎지 않는 불의 폐허, 브리사고 호수의 테라스 섬과 회의장, 새벽빛의 도시와 풀밭

## 1페이지 저장 경로: .work/ep065-p1-notext.png
칸1(와이드, 크게, 몽타주): 인류가 힘을 얻어 온 연대기 한 장 — 왼쪽에 원시인의 모닥불과 움막, 가운데에 검은 증기 기관차와 굴뚝 연기, 오른쪽에 전기 불빛이 쏟아지는 하늘빛 고층 도시, 시간이 왼쪽에서 오른쪽으로 흐르는 삼등분 몽타주 구도
칸2(미디엄, 수평): 1933년의 밤, 홀스텐의 다락 실험실 — 유리기구와 계기판 사이에서 홀스텐이 시험관 하나를 두 손으로 들어 눈앞까지 가져오는 순간, 시험관 속 액체가 은은한 청록빛으로 빛나고, 촛불과 램프 빛이 어우러진 실내
칸3(클로즈업): 빛나는 시험관을 받쳐 든 두 손 클로즈업 — 떨리는 손가락 사이로 청록빛이 새어 나와 둥근 안경에 반사되고, 화면 위쪽 가장자리로 놀란 홀스텐의 눈이 살짝 보임
칸4(와이드, 부감): 석탄 시대의 끝 — 낡은 굴뚝과 검은 연기가 한쪽 구석에 밀려나고, 은빛 탑과 공중 도로, 하늘을 나는 깨끗한 비행선으로 가득한 밝은 원자력 도시를 위에서 내려다본 전경, 곳곳에 민트빛 옥상 정원
칸5(미디엄 투샷, 옥상 테라스): 노을의 옥상에서 홀스텐과 러틀리지 노교수가 나란히 도시를 내려다보며 대화 — 노교수는 뿌듯한 미소, 홀스텐은 어딘가 불안한 눈, 테라스 난간 위에 커피 잔 두 개
칸6(조용한 클로징, 클로즈업): 군수 창고의 유리 진열장 안 — 진홍빛 벨벳 위에 놓인 야광 같은 카롤리늄 금속 덩어리 하나, 유리 너머로 흰 장갑의 군수 장교 손이 다가오는 그림자, 차가운 창고 조명

## 절차
1. 1페이지 프롬프트 = 고정 스타일 블록 + 사양 + 시트 + 칸1~6 묘사. image_gen으로 생성 → .work/ep065-p1-notext.png 저장
2. python3 PIL로 검증: PNG, 1024x1536, 300,000바이트 이상. 실패 시에만 재생성(성공하면 절대 재생성 금지)
