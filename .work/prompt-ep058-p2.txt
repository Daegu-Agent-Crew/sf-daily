#058 「정복자 로뷔르」(Robur le Conquérant, 1886) — 3페이지 칸만화 생성 지시 (2페이지, 1페이지 참조 첨부)

첨부한 이미지는 이번 화의 완성된 1페이지(.work/ep058-p1-notext.png)다 — 같은 캐릭터 시트, 같은 팔레트, 같은 붓결을 그대로 이어 받아 2페이지를 그린다. 너(당신)는 내장 image_gen 도구로 no-text 만화 페이지 1장을 생성한다. 모든 지시를 그대로 따르고, 스크립트는 수정 없이 실행한다. git 명령 사용 금지.

## 고정 스타일 블록 (모든 이미지 프롬프트 첫머리에 그대로 삽입)
bright casual webtoon style, vivid pastel colors (sky blue, cream, coral, mint), soft bold linework, rounded friendly character design, expressive exaggerated faces, flat colors, cheerful bright lighting, clean readable composition

## 공통 사양
- 페이지: 1024x1536 세로, 2x3 여섯 칸 그리드(왼쪽→오른쪽, 위→아래 읽기), 흰 여백 거터, 칸 테두리 둥근 사각
- 절대 규칙: 어떤 글자·숫자·로고·말풍선·캡션 박스도 그림에 넣지 않는다(NO TEXT). 텍스트는 나중에 오버레이한다
- 캐릭터·배경 시트(첨부 1페이지와 동일 유지 — 이 문장을 그대로 재사용해 연속성을 지킨다):
  로뷔르: 정체불명의 엔지니어, 40대 초반, 짧은 검은 머리에 짧게 깎은 검은 수염, 넓고 곧은 어깨와 침착한 매서운 눈, 짙은 청색 더블 재킷에 금색 단추
  프루던트: 웰던 연구소 회장, 통통한 50대, 벗겨진 정수리에 흰 구레나룻, 갈색 프록 코트와 회색 조끼, 흥분하면 얼굴이 새빨개짐
  에반스: 연구소 비서, 키 크고 마른 40대, 금발에 짧은 콧수염, 초록 여행 재킷, 영민한 눈
  프라이콜린: 프루던트의 하인, 깡마른 검은 머리 청년, 커다란 눈, 낡은 갈색 옷, 늘 겁에 질린 표정
  알바트로스호: 길이 30미터의 배 모양 비행선 — 짙은 청록 선체와 나무 갑판, 갑판 위 높은 마스트들에 작은 두 날개 프로펠러가 여러 층으로 총 36개(돌아가는 것은 반투명 원반), 선수와 선미에 커다란 추진 프로펠러가 각각 1개

## 2페이지 저장 경로: .work/ep058-p2-notext.png
칸1(와이드): 새벽의 파리 상공 — 지나가는 알바트로스호 갑판에서 에반스가 난간에 기대어 아래 도시를 내려다보고, 프루던트는 팔짱을 낀 채 딱딱한 얼굴; 아래로 전기 가로등이 반짝이는 옥상들과 강, 배 그림자가 스치듯 지나감
칸2(무음 부감, 가장 크게 — 텍스트 없음): 세계 일주의 대륙 몽타주 — 물결치는 사하라의 모래 언덕들, 초록 띠 같은 강, 계단식 들판과 바다를 잇는 광대한 풍경 위로 아주 작은 알바트로스호가 가느다란 그림자 한 줄을 남기며 지나감; 하늘은 민트·크림 파스텔, 화면 대부분이 대지와 구름
칸3(오버숄더 일출): 태평양 상공의 일출 — 로뷔르의 등 뒤 어깨 너머로 보이는 주황·크림빛 바다와 구름, 선체 옆 커다란 추진 프로펠러의 실루엣; 로뷔르는 바람에 한쪽 눈을 가늘게 뜨고 수평선을 바라보고, 갑판에는 두 사람의 길게 늘어진 그림자
칸4(밤 미디엄, 긴장): 갑판 뒤 그늘에 숨은 프루던트와 에반스 — 도끼를 든 프루던트가 프로펠러 마스트 쪽으로 한 발짝 내딛고, 에반스가 등 뒤를 살피며 손짓; 창백한 달빛과 갑판 등의 따뜻한 불빛 대비
칸5(코믹 클로즈업): 폴대를 부여잡은 프라이콜린의 얼굴 클로즈업 — 바람에 완전히 날리는 검은 머리, 동그랗게 커진 눈, 물러터진 입; 배경으로 빙글빙글 도는 프로펠러 원반과 스치는 구름들
칸6(크게 다이내믹): 산더미처럼 부푼 몬스터 구름(민트·크림·연보라 파스텔 유지) 사이를 가르고 나아가는 알바트로스호 — 갑판 한가운데에 서서 태연히 망원경을 든 로뷔르, 곁에서 우산이 뒤집히고 옷자락이 펄럭이는 프루던트(코믹)

## 절차
1. 2페이지 프롬프트 = 고정 스타일 블록 + 레이아웃 사양 + 캐릭터 시트 + 칸1~6 묘사. image_gen으로 생성 → .work/ep058-p2-notext.png 저장
2. python3 PIL로 검증: PNG, 1024x1536, 300,000바이트 이상. 실패 시에만 재생성(성공하면 절대 재생성 금지)
3. 결과 요약 출력
