#063 「혜성」(The Comet, 1920) — 2페이지 칸만화 생성 지시 (1페이지)

너(당신)는 내장 image_gen 도구로 no-text 만화 페이지 1장을 생성한다. 모든 지시를 그대로 따르고, 스크립트는 수정 없이 실행한다. git 명령 사용 금지.

## 고정 스타일 블록 (모든 이미지 프롬프트 첫머리에 그대로 삽입)
bright casual webtoon style, vivid pastel colors (sky blue, cream, coral, mint), soft bold linework, rounded friendly character design, expressive exaggerated faces, flat colors, cheerful bright lighting, clean readable composition

## 공통 사양
- 페이지: 1024x1536 세로, 2x3 여섯 칸 그리드(왼쪽→오른쪽, 위→아래 읽기), 흰 여백 거터, 칸 테두리 둥근 사각
- 절대 규칙: 어떤 글자·숫자·로고·말풍선·캡션 박스도 그림에 넣지 않는다(NO TEXT). 텍스트는 나중에 오버레이한다
- 캐릭터·배경 시트(1·2페이지 동일 유지 — 이 문장을 그대로 재사용해 연속성을 지킨다):
  짐 데이비스: 키 크고 말수 적은 흑인 은행 심부름꾼, 짙은 갈색 피부와 크고 부드러운 눈, 감수성 있는 둥근 얼굴, 낡은 카키색 작업복 조끼에 회색 바지, 챙 낡은 중절모
  줄리아: 25세 전후의 우아한 백인 여인, 어두운 금발을 올려 묶고, 아이보리 실크 드레스에 진주 목걸이, 표정이 풍부하고 서글픈 아름다움
  은행장: 둥글고 뚱뚱한 은발의 프록코트 신사, 회색 짧은 수염, 후원스러운 미소
  짐의 아내: 작고 야윈 갈색 피부의 여인, 민트색 숄을 두르고 앞에 작은 천 꾸러미를 감싸 안음
  배경: 1920년대 맨해튼 — 정오의 브로드웨이 은행 돌계단(실크모자 신사들과 모자 쓴 부인들의 인파, 신문 파는 소년), 은행장 실내 책상, 최하부 금고(거대한 돌문과 녹슨 철 보물궤, 손에 든 등불), 텅 빈 월스트리트(멈춘 전차와 마차), 호텔 레스토랑, 밝은 5번가와 육층 창문

## 1페이지 저장 경로: .work/ep063-p1-notext.png
칸1(와이드 설정, 크게): 1920년대 정오의 맨해튼 브로드웨이 — 커다란 돌 은행 계단 위에 선 짐이 계단 아래로 흐르는 인파(실크모자 신사, 깃털 모자 부인들, 들어 올린 신문)를 조금 떨어져 바라보고, 하늘 한구석에 작게 빛나는 혜성(별과 옅은 꼬리), 사람들은 하나같이 입을 벌려 떠들어 대는 수다스러운 표정
칸2(클로즈업): 은행장의 실내 책상 앞 — 둥글고 은발인 은행장이 프록코트 자락을 펴고 종이를 내밀며 짐을 향해 후원스러운 미소를 짓고, 옆모습의 짐이 씁쓸한 옅은 미소로 그것을 받는 모습, 배경에 둥근 금고 문과 걸린 시계(바늘만, 숫자 없이)
칸3(앙각, 인테리어): 최하부 금고 내부 — 짐이 손에 든 등불로 어둠을 비추며, 바닥에 놓인 녹슨 커다란 철 궤짝에서 새어 나오는 황금빛 광채를 내려다보고, 그의 등 뒤로 거대한 돌문이 회전하며 닫히려는 순간(먼지가 피어오르고 문짝에 움직임선), 비좁고 신비한 지하 공간
칸4(무음 칸, 와이드 부감): 정오의 월스트리트를 위에서 내려다본 전경 — 텅 빈 넓은 거리에 얌전히 누운 듯 쓰러진 사람들, 한가운데 멈춰 선 전차와 마차, 굴뚝 연기가 멈춘 건물들, 화면 앞쪽 구석에 신문을 든 채 고개를 떨군 신문 소년, 기묘하게 고요한 옅은 파스텔 빛의 도시
칸5(미디엄): 화려한 호텔 레스토랑 창가 식탁 — 짐이 하얀 식탁에 혼자 앉아 은촛대 트레이 위의 빵과 수프를 조용히 먹고, 높은 샹들리에가 반짝이는 텅 빈 홀의 긴 식탁들, 그의 무표정 속에 스며든 쓸쓸함, 창밖 고요한 거리
칸6(앙각, 크게): 밝은 낮의 5번가 — 화면 아래쪽에 달리는 검은 박스형 포드 자동차의 운전석에서 짐이 놀란 얼굴로 위를 올려다보고, 높은 육층 창문으로 금발의 줄리아가 상반신을 내밀고 입을 크게 벌려 외치며 한 손을 내젓는 급박한 순간, 창틀에 커튼이 펄럭임

## 절차
1. 1페이지 프롬프트 = 고정 스타일 블록 + 사양 + 시트 + 칸1~6 묘사. image_gen으로 생성 → .work/ep063-p1-notext.png 저장
2. python3 PIL로 검증: PNG, 1024x1536, 300,000바이트 이상. 실패 시에만 재생성(성공하면 절대 재생성 금지)
