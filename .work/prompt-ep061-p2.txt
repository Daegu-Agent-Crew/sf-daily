#061 「우주 밖의 색」 — 2페이지 칸만화 생성 지시 (2페이지, 1페이지 참조 첨부)

첨부한 이미지는 이번 화의 완성된 1페이지(.work/ep061-p1-notext.png)다 — 같은 캐릭터 시트, 같은 팔레트, 같은 붓결을 그대로 이어 받아 2페이지를 그린다. 너(당신)는 내장 image_gen 도구로 no-text 만화 페이지 1장을 생성한다. 모든 지시를 그대로 따르고, 스크립트는 수정 없이 실행한다. git 명령 사용 금지.

## 고정 스타일 블록 (모든 이미지 프롬프트 첫머리에 그대로 삽입)
bright casual webtoon style, vivid pastel colors (sky blue, cream, coral, mint), soft bold linework, rounded friendly character design, expressive exaggerated faces, flat colors, cheerful bright lighting, clean readable composition

## 공통 사양
- 페이지: 1024x1536 세로, 2x3 여섯 칸 그리드(왼쪽→오른쪽, 위→아래 읽기), 흰 여백 거터, 칸 테두리 둥근 사각
- 절대 규칙: 어떤 글자·숫자·로고·말풍선·캡션 박스도 그림에 넣지 않는다(NO TEXT). 텍스트는 나중에 오버레이한다
- 캐릭터·배경 시트(1·2페이지 동일 유지 — 이 문장을 그대로 재사용해 연속성을 지킨다):
  나홈 가드너: 50대 뉴잉글랜드 농부, 넓은 어깨와 햇볕에 그을린 얼굴, 짚색 중간 머리와 깊은 주름, 갈색 오버올 작업복과 멜빵, 밀짚모자, 무뚝뚝하지만 따뜻한 눈
  사디어스: 20대 맏아들, 아버지를 닮은 넓은 골격과 주근깨, 하늘색 셔츠에 갈색 멜빵 바지
  지나스: 10대 둘째 아들, 장난기 어린 뾰족한 머리카락, 크림색 셔츠에 민트색 조끼
  머윈: 10대 막내 아들, 코랄색 셔츠, 동그란 놀란 눈
  내비: 40대 어머니, 흰 머리수건과 크림색 블라우스, 긴 갈색 치마, 다정하지만 불안해하는 눈매
  아미티지: 60대 대학 지질학 교수, 흰 수염과 둥근 안경, 검은 빅토리안 코트와 지팡이, 탐구하는 표정
  배경(2페이지): 같은 계곡 농장의 깊어 가는 늦가을 — 비어 가는 집 내부(부엌), 우물, 잿빛으로 변한 밭과 과수원
- 특별 팔레트 — '색(the Colour)': 지구에 없는 빛깔. 밝은 팔레트 안에서도 생경하게 빛나는, 일렁이는 아이리디센트 발광(민트와 산호가 섞여 유리처럼 맑게 흔들리는 빛). 페이지 전체 팔레트는 밝고 캐주얼 유지

## 2페이지 저장 경로: .work/ep061-p2-notext.png
칸1(미디엄, 낮): 가축의 이상 — 풀을 입에 대지 않은 채 우물 쪽만 바라보는 절소 떼, 바구니에 쌓인 겉만 반짝이는 사과에 앉은 파리, 이마에 손을 얹고 한숨 쉬는 나홈
칸2(부감, 세로 구도): 우물 청소 — 우물 입구에서 아래를 내려다본 시점, 두레밍 줄을 잡고 어두운 우물 속으로 내려가는 머윈과 지나스의 작아지는 뒷모습, 우물 벽의 이끼와 일렁이는 물그림자
칸3(앙각, 다이내믹): 우물에서 기어 나온 머윈 — 새하얀 얼굴로 팔을 내저으며 헛간 쪽으로 필사적으로 도망치는 순간, 뒤로는 우물 입구의 희미한 빛, 흩날리는 짚과 먼지
칸4(미디엄, 실내): 텅 빈 부엌 — 혼자 식탁에 앉은 앙상해진 나홈, 꺼진 등잔과 차가운 창, 옆으로 놓인 빈 의자들, 창밖 어둠 속 과수원의 그림자
칸5(클로즈업, 다이내믹): 문가에 기댄 나홈의 마지막 얼굴 — 떨리는 입술과 젖은 눈, 뒤편으로 와르르 무너져 내리는 집의 지붕과 목재 파편, 폭풍우의 검은 바람
칸6(와이드, 새벽, 무음 훅): 물안개 낀 새벽의 계곡 — 우물에서 뿜어 올라 하늘 끝으로 사라지는 한 줄기 일렁이는 빛기둥, 그 아래 잿빛으로 변한 밭과 과수원, 아주 작게 서서 올려다보는 한 사람의 실루엣

## 절차
1. 2페이지 프롬프트 = 고정 스타일 블록 + 사양 + 시트 + 칸1~6 묘사 + 첨부 1페이지 참조. image_gen으로 생성 → .work/ep061-p2-notext.png 저장
2. python3 PIL로 검증: PNG, 1024x1536, 300,000바이트 이상. 실패 시에만 재생성(성공하면 절대 재생성 금지)
